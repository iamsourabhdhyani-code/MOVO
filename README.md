## Features

- Local Video Playback
- Continue Watching
- Smart Media Library
- Quick Seek Controls
- Double-Tap Seek
- Swipe Controls for Brightness & Volume
- Audio Tracks
- Subtitles
- Picture-in-Picture
- Playback Speed
- Aspect Ratio & Fit Modes
- Orientation Control
- Auto Play Next
- Clean Player Interface
